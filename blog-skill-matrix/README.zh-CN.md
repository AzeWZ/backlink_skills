# 博客技能矩阵

[English](README.md) · 版本 0.14.0 · [MIT 许可证](LICENSE)

面向普通、独立有用的 SEO 博客文章，兼顾质量、耗时和模型用量。内容制作自动化，发布由人工完成。本版缩减技能入口和重复记录，不改变 G/R 的职责、模型配置或发布权限。

## 组成

| 组成 | 用途 |
| --- | --- |
| `blog-gate` | 汇总写前调研与完整方案，取得用户确认，安排作者，验收需求，检查公开页 |
| `blog-writer` | 连续研究、关键词本地化、写作、配图、生成载荷和一次自查 |
| `blog-review`（可选） | 仅用户明确选择时做独立审稿 |
| 内部工具与参考 | 平台匹配归 G；编辑标准、模板和生成/检查工具归 W，不再是额外技能 |

日常从 `$blog-gate` 启动。默认 WQ 仍由作者在同一上下文自查；WR 仍须用户明确选择独立 R。不是 G/R 合并版，不因风险自动增加独立审稿。

## 完整流程

调研与方案 → 用户确认 → W 成稿、配图并生成/检查最终 HTML 与 Markdown 载荷 → WQ 作者自查或已选 WR 独立 R 审最终可视化载荷 → G 对照原要求验收并正式交付 → 人工发布 → 同一 G 检查公开页。

载荷先交 R 是内部送审，不是已批准的人工发布包。R 看最终可视化页面与实际图片，不只审源稿；通过后的材料变更只复核受影响内容及直接关联，旧结论不自动覆盖新版本。不新增审稿轮次或版本报告。

多个文章可由少量可见、可复用作者按互不重叠路径并行。G 维护共享要求/进度，作者只写本篇。一篇受阻不拖住其他已确认任务；不把一篇拆成研究、写作、自查多个代理。

## 最小文件与交付

- 一份 `task-plan.json` 保存共享要求和逐篇差异，原用户确认单独保存。模板为 `templates/task-plan.json`；只记已确认要求，不把暂定大纲或经验性字数变成门槛。
- 每篇 `articles/<ID>/canonical/article.md` 包含正文、SEO 信息、图片说明和必要来源引用；素材放本篇目录。作者不再维护多份同义正文/元数据/图片记录。
- 工具生成 `handoff/visual-payload.html` 和 `handoff/visual-payload.md`，以及一个隐藏的机械一致性记录。页面依次显示标题、带准确中文插图注释/可见 Alt 的正文、SEO title/tags/description 及独立 Excerpt（文章摘要），没有复制按钮。
- 正文图按确认要求编号为 PNG/JPG/JPEG，默认另备独立封面 `00-cover-...`，封面不顶正文首图。
- 正常质量通过留短结论；有问题才记位置、影响和处理结果。不写全绿报告，不常规重跑全文审稿。

[短流程](docs/workflow-core.md)是压缩恢复后的必读页。作者的[单稿用法](skills/blog-writer/references/markdown-authoring.md)包含格式和命令；[编辑标准](skills/blog-writer/references/editorial-standard.md)按当前问题读取。

## 需求保护

平台只从用户提供且确认的范围选择，每篇独立映射。写前以实际首页/Trending/Popular/Featured 文章核平台主流语言，不能拿界面语言、历史账号或“能显示”代替。冲突先报用户，不擅换平台或强投。

用户主词的全部核心含义逐篇继承；跨语言优先适用品牌本地表达，再查地区自然变体，仍无共识才记录模型翻译。标题突出本篇问题、避免同一长前缀模板；只有锁定原文才逐字检查，不设正文密度配额。Trends 可选且不证明搜索量或当地热度。

正文独立有用，产品推荐次要但指定 CTA、锚文本、链接和披露必须保留。目标站介绍/推荐/来源链接按实际次数合计，只有用户约定才设数量或上限；多锚多链接不一律禁止，也不承诺零删除风险。图片须真正讲对方法，逐张实际查看，图文风格尽量呼应品牌。

G 对照原确认和最终产物，不只看作者配置是否自洽；质量判断仍由 W 或已选 R 完成，G 不重审全文。

## 工具与兼容

Python 3.9+。Markdown 新路线需要 `markdown-it-py==3.0.0`，可在隔离环境安装内部依赖文件 `skills/blog-human-handoff/scripts/requirements.txt`。新任务不必运行机架初始化、派发门、审稿索引或旧包验收链。

旧工具所在目录保留以兼容路径，但已移除四个独立技能入口。已有 `campaign.json`、文章包或审稿索引的项目沿用原规则，不自动迁移。旧细节见 [README.legacy.zh-CN.md](README.legacy.zh-CN.md)，只在历史项目需要时读；不得据此给新任务补门禁。

用户仍人工登录、粘贴、插图、预览、发布和修复；注册/登录及最低账号设置只能按[独立授权](docs/account-preparation.md)执行。本地生成、机械检查和作者自查均不等于独立 R 批准或公开发布。URL 回传后同一 G 只查传递保真，人工接受且公开检查通过才计完成。

本版没有预设 token 节省比例。以实际普通稿运行和人工返工衡量收益。
