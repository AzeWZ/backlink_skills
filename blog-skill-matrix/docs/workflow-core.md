# 博客短流程

压缩、恢复或交接后先完整重读本页，再读用户确认的任务、本篇当前稿和未解决问题。旧报告与工具细节按需查看。

## 组成与角色

常用技能只有 `blog-gate`（G，主控）和 `blog-writer`（W，作者）；`blog-review`（R）仅用户明确选择独立审稿时启用。此次不合并 G/R，不把风险当作自动启用 R 的授权。平台匹配是 G 的按需参考，编辑标准和人工交付是 W 的参考/工具；机架只为旧项目兼容，不是新任务必经流程。

## 完整顺序

1. **调研与方案。** G 收集要求，汇总产品事实、逐篇读者问题、关键词/本地化路径、平台匹配、品牌风格、CTA、事实边界、图片和交付安排。每次新任务给一次必要人工准备清单，只读调研不能扩展用户平台范围。
2. **用户确认。** 用户看清全部逐篇方案并明确确认后，才派文章作者、写正式稿和生图。一份任务方案保存共享要求与各篇差异，并保留原确认消息来源。临时大纲或模型建议不是新增硬要求。
3. **连续成稿。** 少量可见 W 可安全并行、持续复用；每篇只写自己的 `articles/<ID>/`。W 连续完成研究、Markdown、SEO 信息、图片/封面和双发布页，不把一篇拆成多个阶段代理，不重做适用共享调研。
4. **一次质量核验。** W 先生成并机械检查最终 HTML/Markdown 载荷，备齐全部最终图片/封面；然后默认同一 W 自查，已选 WR 才把载荷交独立 R，不能只审源稿或源码。R 看最终可视化页面、重要来源与实际图片，不再叠加 W 的正式完整自查。真实问题定向修复后重生成，原质量角色只确认变更及直接影响，旧结论不自动覆盖新载荷。正常通过留短结论，不写全绿报告、不常规全文复审；重大不能关闭的问题如实交用户决定。
5. **需求验收与交付。** 载荷送 R 是内部审核；当前版本质量通过后才由 G 验收并正式交用户发布。G 对照用户原确认和最终交付，核数量、映射、语言、关键词含义、CTA/披露、链接约定、图片及两个载荷入口，不重做全文质量审查。不只看作者后填配置是否自洽。
6. **人工发布。** 人工登录、复制、插图、预览、发布和修复。G 保存进度后结束执行，等待消息，不轮询或反复编译。注册/登录及最低账号设置仅另获具体授权时执行，不授予稿件写入或发布权限。
7. **公开页检查。** 用户回传 URL 和接受/需修复结论后，同一 G 只读比对发布传递。标题层级只看公开页渲染视觉，不以编辑器或源码标签裁定。平台传输问题交人工修复，只检查受影响项；只有用户要求改稿才回原质量路线。人工接受且公开检查通过才计完成。

## 必须保留，其他由模型决定

- 平台只来自用户提供且已确认范围，每篇独立映射；语言依据实际首页/Trending/Popular/Featured 文章，不能用界面或“能显示”代替主读者语言。冲突先报用户，不强投、不擅译或换平台。
- 用户主关键词及全部保护含义逐篇继承，角度不能替代主词。自然本地化优先适用品牌表达，再查地区变体，仍无共识才用记录明确的模型翻译；Trends 可选，仅英文全球相对关注度背景，不虚报搜索量/热度。标题/预期 H1 自然表达全部含义并突出各篇问题，只有明确锁定原文或旧确认才逐字要求。H2/H3 具体，不设密度配额。
- 正文独立有用，事实可靠、不编造实测。指定 CTA 必须保留，推荐次要、贴题且披露真实关系；默认 founder 不证明账号权限。多锚多链接按用户约定计实际出现次数，不自行设上限；避免低价值挂链，不承诺零平台删除风险。
- 图文尽量呼应品牌；按已确认数量、比例和首中尾需求做准确方法图，正文之外默认另交封面。素材为编号 PNG/JPG/JPEG，逐张实际查看，Alt/图注准确；准确文内图片注释不能用独立清单替代。
- 同源交付可视化 HTML 与 Markdown，顺序为标题、带图片注释的正文、SEO title/tags/description 及独立 excerpt（文章摘要），无复制按钮。作者维护一份 Markdown 和图片，程序生成投影、计数和一致性记录，不替模型判质量。
- G 维护任务/共享进度，W 只写本篇；普通路径独立文章可并行，Git 工作树仅因真实写入冲突、高风险隔离或用户要求建立。不为填槽位新开会话，不调整既有模型配置。

## 新任务与旧项目

新任务用一份 `task-plan.json`、逐篇 Markdown/图片和程序生成的两个发布页；问题/质量结论与进度保持简短，来源贴近主张记录。只对照原需求、最新产物和真实问题，不新增审批、契约链或完整历史读取。

已有 `campaign.json`、文章包和审稿索引的项目继续原规则；只有恢复或兼容需要时读旧接口，不能静默迁移、删除历史或放宽旧确认。原代码保留为内部工具；脚本输出只证明机械检查，不证明用户授权、独立审稿或公开发布。
